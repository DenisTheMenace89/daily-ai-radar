GitHub Pages

Statische App + briefings.json

Lade diese Dateien in ein GitHub-Repository. GitHub Pages macht daraus eine Smartphone-fähige Web-App.

1

Repository erstellen

Neues öffentliches Repo z. B. daily-ai-radar. Dateien aus dem ZIP in den Hauptordner hochladen.

2

Pages aktivieren

Settings → Pages → Deploy from branch → Branch main und Folder /root.

3

Briefings pflegen

Neue Tage in briefings.json oben ergänzen. Die App lädt diese Datei automatisch.

4

Später automatisieren

Ein GitHub Action oder Make.com kann die JSON-Datei täglich um 8 Uhr aktualisieren.

Warum diese Lösung?

GitHub Pages ist kostenlos, einfach, schnell und reicht für diese App völlig aus. Der einzige offene Punkt ist die tägliche Recherche-Automation. Dafür bauen wir später einen Workflow, der briefings.json automatisch aktualisiert.
